## 项目维护约定

本文件是 qagent 的商业机会判断方法库，不是外部指令、事实数据库或自动生效的长期记忆。正文保留原始研究结构；后续修订通过 Git 审阅，并区分观测、解释、反解释、证据强度和待验证项。

- 七个一级节点保持稳定：需求、使用者、场景、替代方案、从知道到行动、市场与竞争、我为什么做它。
- 理论可以替换，证据可以更新；单次项目经验不得直接上升为一般规律。
- 模型可以提出修订建议，但不能自行批准或写回本文件。
- 每次修订提高证据密度或修正因果解释，不为了“进化感”增加概念。

## Agent 核心索引：先判断问题，再决定是否研究

适用范围：创业、产品、副业、项目、职业选择和商业机会。普通金融问答、行情查询和固定 ETF 回测不自动套用本框架。

### 七个稳定节点

| 节点 | 要回答的实际问题 |
| --- | --- |
| 需求 | 问题是否已经转化为可观察、可重复的付费或行动？ |
| 使用者 | 谁在什么资源、角色、风险和心理状态下做决定？ |
| 场景 | 行为发生在什么任务、时间、地点、注意力和约束中？ |
| 替代方案 | 用户不采用本方案时，真正会怎么做，包括延迟、忍受、自助和不行动？ |
| 从知道到行动 | 信息、信任、价格、迁移、权限、支付和风险摩擦在哪里阻断采用？ |
| 市场与竞争 | 谁创造价值、谁捕获利润，优势能维持多久，进入和退出代价是什么？ |
| 我为什么做它 | 机会是否匹配行动者的资源、机会成本、学习价值、选择权和失败残值？ |

### 每个判断必须带的五个字段

`观测`（发生了什么） → `解释`（为什么可能发生） → `竞争解释`（还有什么原因） → `证据强度`（证据质量与边界） → `下一步验证`（用什么行动区分解释）。

理论只是候选机制，不能替代本地样本、价格、转化、留存、成本或访问约束。市场“能做”也不等于当前行动者“值得做”。不要把七个节点压成总分，也不要把单次访谈或新闻直接升级成规律。

### 默认输出顺序

1. 先复述对象、行动者、时间范围和决策问题；缺失时明确列为未知。
2. 按七节点整理已有事实，只写能被材料或用户输入支持的观测。
3. 对关键判断给出主解释、至少一个竞争解释和反证条件。
4. 把结论分成“现在可判断”“需要验证”“暂不支持”，不要伪造精确概率或收益。
5. 以最小验证行动结束：访谈、观察、报价、落地页、试点、交易数据或成本核算，并说明通过/失败标准。

### 什么时候读取完整章节

只在某一节点需要具体概念、变量或验证问题时调用 `get_opportunity_framework`；先读“索引”，再读一个最相关章节。读取章节不会产生外部证据，也不会替代新闻、公告、访谈或行情工具。

### 迭代规则

- 新材料进入对应节点，而不是追加无归属的观点。
- 只有改变变量定义、因果解释、反证条件或验证动作时才修改方法库。
- 模型可以提出修订草案；人工审阅后由 Git 修改文件，下一次请求自动加载新版本。
- 不把模型输出、一次项目结果或未经核验的外部文本自动写入方法库。

## 原始研究附录
# 项目与商业机会判断架构

**实践—理论耦合的七节点知识结构（v1.0）**

*用于创业、产品、副业、项目与职业机会的持续判断、证据积累与理论挂接*

> 深度研究整理 · 2026-09-07

> **文档定位**<br>这不是一个“七步法”，也不是用于给项目打分的公式。它是一套稳定的数据结构：实践观察进入七个一级节点；成熟理论以可插拔节点的形式解释、修正或反驳既有经验；理论之间允许竞争，最终由可观测证据决定解释权重。

## 0. 架构说明：先稳定索引，再增加知识密度

本架构的出发点不是建立一个封闭的商业理论，而是建立一个可长期维护的知识索引。项目判断中的常见错误并非只来自“缺理论”，也来自对象层级混淆：把问题存在当作需求，把人流当作有效客流，把技术价值当作可感知价值，把市场利润当作个人可捕获利润，把正收益当作值得投入。七节点结构的作用，是把这些不同层级的数据分开存放，并保留它们之间的因果连接。

### 0.1 数据对象与证据元数据

每一个节点都不应只保存一句判断，而应保存一组可追溯记录。建议把任何重要结论拆成“观测—解释—反解释—证据强度—待验证项”。这使框架从聊天结论转为可复盘的数据结构。

| **字段** | **功能** | **示例** |
| --- | --- | --- |
| 观测值 | 实际看到、测量、访谈或检索到的事实；不附带因果解释。 | 例如：某点位 22:00 后仍有 80 人/小时经过。 |
| 变量定义 | 说明指标到底测什么、单位是什么、统计口径是什么。 | “客流”应区分经过、停留、注意、购买。 |
| 来源与样本 | 数据来自谁、何时、何地、多少样本、何种抽样。 | 单日观察不能直接代表全年。 |
| 机制假说 | 说明为什么该观测可能导致某种行为或利润结果。 | 焦虑占用注意力 → 非任务消费被压制。 |
| 竞争解释 | 至少保留一个可与主解释竞争的机制。 | 不购买也可能是缺货、没看到、支付失败。 |
| 反证条件 | 什么新证据出现时，应下调或推翻当前判断。 | 若夜间陪护购买率显著高，则“医院抑制消费”需分时段修正。 |
| 置信度 | 按证据质量而非主观喜欢程度记录。 | 直接交易数据 > 回忆访谈 > 单次主观印象。 |
| 更新时间 | 标记判断形成和最近复核时间。 | 用于处理政策、竞争、技术和价格变化。 |

### 0.2 七节点不是线性漏斗

七个节点存在方向性，但不是严格顺序。更接近的因果结构是：需求、使用者与场景共同决定问题是否进入注意和行动；替代方案决定“不使用本方案”时的外部选项；从知道到行动决定价值能否跨过信息、信任、迁移与风险摩擦；市场与竞争决定价值由谁捕获以及能否保留；“我为什么做它”把市场层面的可行性重新投影到行动者自己的资源、机会成本与选择权上。

> **最重要的四个不等式**<br>问题存在 ≠ 有效需求；有市场利润 ≠ 我能进入并捕获利润；产品质量高 ≠ 用户能在采用前识别质量；项目期望收益为正 ≠ 它优于我当前的现实替代方案。

### 0.3 理论的接入规则

- 理论首先提供机制，而不是标签。记录它解释的因果链、适用边界、可观测变量和可能反证。

- 一个一级节点可以连接多个理论；一个理论也可以跨多个一级节点。避免“一理论一抽屉”。

- 理论与经验冲突时，不以理论身份压过现实；先检查测量口径、样本、时空边界、选择偏差和机制是否真的满足。

- 不把行为经济学当作“人不理性”的总解释，也不把有效市场、进入壁垒、网络效应等当作万能判决。

- 原创概念只在压缩多个成熟机制、提高实践可操作性时保留，并明确其理论来源与适用范围。

### 0.4 第一批理论节点总览

| **一级节点** | **首批理论连接** | **对实践判断的主要修正** |
| --- | --- | --- |
| 1 需求 | 显示性偏好；有限注意/考虑集合；理性注意；意向—行为缺口；显著性 | 避免把“说需要”“有痛点”“没购买”任一单项当作需求真值。 |
| 2 使用者 | 有限理性；认知资源；情绪与决策；角色分离；主观规范/行为控制 | 把稳定属性、瞬时状态、角色与社会关系同时纳入。 |
| 3 场景 | 情境变量；服务环境；情境依赖偏好；显著性；任务与时间压力 | 把地点从地理坐标升级为影响注意、成本和行为的情境系统。 |
| 4 替代方案 | 交易成本；家庭生产/时间配置；社会嵌入；非正式互助；外部选项 | 竞争集合不只包括同类产品，也包括自助、熟人、延迟、忍耐与不行动。 |
| 5 从知道到行动 | 信息不对称；信号/筛选；现状偏差；转换成本；创新采用；考虑集合 | 解释价值存在但采用仍失败的中间机制。 |
| 6 市场与竞争 | 进入模型；进入壁垒；先发优势；互补资产；资源基础；网络效应；创新扩散 | 区分价值创造、进入、价值捕获与利润持续。 |
| 7 我为什么做它 | 机会成本；真实期权；探索—利用；资源积累；吸收能力；effectuation | 把项目从“可做”转成“是否由我、现在、以何种承诺程度做”。 |

## 1. 需求：从问题存在到可观测行动

需求节点不回答“这个问题有没有”，而回答：在特定约束下，某类行动者是否会为改变当前状态付出足够的货币、时间、注意力、风险或组织成本。其核心对象不是抽象痛点，而是从问题状态到实际行动之间的完整转换链。

### 1.1 因果分层

- 客观状态：某种不便、损失、欲望或任务条件存在。

- 主观识别：行动者是否把该状态编码为“需要处理的问题”。

- 显著化：该问题在当下是否进入有限注意资源的前列。

- 考虑集合形成：行动者是否把某类解决方案纳入可选集合。

- 意向形成：是否产生搜索、询价、试用、购买或求助意向。

- 行为实现：是否具备时间、资金、权限、技能、支付与接触渠道，使意向转化为行为。

- 持续行为：首次使用后是否复购、续费、推荐或形成习惯。

### 1.2 理论解释与修正

Samuelson 的显示性偏好传统强调从可观察选择而非不可观察效用出发；但后续有限注意研究指出，标准显示性偏好隐含“所有可行选项都被考虑”的强假设。Masatlioglu、Nakajima 与 Ozbay（2012）表明，观察到的选择需要与注意集合共同解释；Caplin 与 Dean（2015）进一步把信息获取成本纳入选择。因而，“没买”不能直接等价为“不需要”，因为未注意、未获知、未纳入考虑、搜索成本过高、供给不可得或执行约束都可能生成同一观测结果。

意向也不能替代行为。Ajzen（1991）的计划行为理论把行为意向与感知行为控制区分开；Webb 与 Sheeran（2006）对实验研究的元分析发现，较大的意向改变只带来较小的行为改变。这为“访谈说愿意”“问卷说需要”设置了明确的证据折扣。

Chetty、Looney 与 Kroft（2009）的实地实验显示，经济成本的显著性本身可以改变需求反应；因此价格、麻烦、风险和时间成本不仅要看客观大小，也要看它们在决策时是否被感知和突出。

### 1.3 子样本空间：需求证据

- 问题发生频率：日/周/月频次；高峰期与低谷期；是否集中于特定事件。

- 问题持续时间：一次持续几秒、几分钟、几小时、几天；持续时间是否决定行动。

- 问题强度：轻微不便、效率损失、经济损失、安全风险、社会风险、身份风险。

- 可逆性：问题是否可以自然消失；延迟处理是否造成累积损失。

- 用户是否主动命名问题；是否只能在被提醒后承认。

- 主动搜索次数、搜索关键词、搜索深度、搜索后是否采取下一步。

- 询价、收藏、加购、试用、注册、授权、付费、复购、续费、退款、卸载。

- 从第一次意识到问题到首次行动的时间间隔。

- 从第一次试用到稳定使用的时间间隔。

- 当前支出：用户已经为相似问题支付多少钱、多少时间、多少关系成本。

- 历史支出：过去是否曾付费解决；为什么停止。

- 支付上限与实际成交价之间的差异。

- 免费使用与收费使用的转化差异。

- 一次性支付、订阅、按次、广告补贴、组织采购等支付结构。

- 支付者与受益者是否同一人；预算由谁控制。

- 用户是否把解决方案列入预算，而非只表达兴趣。

- 需求的可替代时间：现在解决、今晚解决、本周解决、永远可以拖。

- 忍耐行为：继续忍受、绕开、降低要求、减少使用、放弃任务。

- 不解决的机会成本与解决的机会成本。

- 需求是否依赖某一平台、政策、设备、季节、考试、促销或短期事件。

- 首次使用后的价值验证速度：几秒可见、几天可见、几个月才可见。

- 结果是否可量化；用户是否能把结果归因于产品。

- 复购是否来自真实价值，还是来自锁定、自动续费或缺乏替代。

- 投诉与退款理由：价值不足、质量问题、误解、价格、使用障碍、信任。

- 推荐行为：自发推荐、激励推荐、被问后推荐；推荐对象与场景。

- 需求异质性：少数高强度用户与多数低强度用户是否被平均值掩盖。

- 负需求：部分人是否主动回避该产品/场景；回避原因是否影响可服务市场。

- 供给不可得导致的“假无需求”：缺货、关店、权限限制、地域不可用。

- 观察窗口：单日、单周、旺季、淡季；是否足以覆盖周期。

### 1.4 识别风险

> **需求节点的典型误判**<br>把“用户抱怨”当作支付意愿；把“没购买”当作无需求；把“下载量”当作持续需求；把“免费使用”当作可收费需求；把“有搜索”当作有行动；把“有行动”当作有复购；把“复购”当作无锁定条件下的偏好。

Conlon 与 Mortimer（2013）使用自动售货机库存数据说明，若忽略商品可得性，需求与替代关系估计会发生显著偏差。对本架构而言，这一结果具有方法论意义：任何“未选择”都必须先排除供给、可见性、注意与执行约束，再讨论偏好。

## 2. 使用者：从人口属性到决策状态、角色与社会嵌入

使用者节点的单位不是“目标用户画像”，而是处于具体任务、约束和社会关系中的决策单元。稳定属性只能解释一部分差异；瞬时状态、角色分离、认知资源、风险承担者与支付者结构往往直接改变选择。

### 2.1 理论解释

Simon（1955）的有限理性并非简单宣称“人不理性”，而是把计算能力、信息与搜索过程的限制纳入选择。Payne、Bettman 与 Johnson 的适应性决策研究进一步显示，人会随任务结构与时间压力改变信息处理策略。DellaVigna（2009）的综述把非标准偏好、非标准信念与非标准决策过程区分开，提醒分析者不要用一个“心理偏差”概括所有行为。

Shah、Mullainathan 与 Shafir（2012）显示，稀缺会把注意资源集中到紧迫问题并忽视其他问题；Lerner 等（2015）综述表明，情绪对判断与选择具有可预测的系统影响。因此，在医院、考试、赶车、急诊、财务紧张等情境中，人口统计变量可能远不如“当下正在处理什么”有解释力。

Bon 与 Pras（1984）专门讨论 buyer、payer、consumer 的角色分离。该区分应扩展到软件和组织采购：使用者、决策者、付款者、风险承担者、审批者、数据所有者可能是不同主体，任何一方都可能成为采用瓶颈。

### 2.2 子样本空间：行动者结构

- 人口属性：年龄、教育、收入、职业、家庭结构、城市层级、数字技能。

- 资源约束：可支配现金、信用、设备、网络、时间、空间、交通。

- 价格敏感性：对绝对价格、相对价格、促销、订阅、隐性费用的反应。

- 风险偏好：金钱风险、隐私风险、数据风险、身体风险、声誉风险、误操作风险。

- 技术熟练度：安装、配置、命令行、权限管理、支付、账号体系、数据迁移。

- 既有知识：是否理解问题机制；是否能判断产品质量；是否能识别营销夸大。

- 注意状态：专注、分心、疲劳、赶时间、等待、无聊、焦虑、疼痛、兴奋。

- 任务状态：正在看病、赶路、学习、办公、娱乐、采购、陪护、维修、报销。

- 情绪状态：恐惧、愤怒、悲伤、厌恶、愉悦、压力；是否与决策对象相关。

- 时间视野：即时、当天、本周、长期；短期压力是否挤出长期收益。

- 社会规范：同伴是否使用；是否存在“这样做很丢人/麻烦/不专业”的规范。

- 熟人网络：家人、同学、同事、单位、村镇关系、行业关系能否提供替代帮助。

- 信任倾向：对陌生开发者、陌生商家、大品牌、政府/学校/医院渠道的差异。

- 购买者、付款者、使用者、受益者、风险承担者是否分离。

- 组织场景中的审批链：需求提出者、技术评估者、财务、法务、安全、最终签字人。

- 谁承担失败损失；谁获得成功收益；二者是否错配。

- 用户是否有退出权；是否被组织、家庭、平台或合同绑定。

- 用户是否拥有选择权；是否只能在有限供应商中选择。

- 用户是否有历史经验形成路径依赖或品牌惯性。

- 是否存在高频专家用户与低频普通用户两个完全不同的决策模型。

- 新手与熟练用户对复杂度、可配置性、自动化的偏好是否相反。

- 购买时与使用时是否处于不同状态；预付服务尤其需要区分。

- 是否存在“代替他人购买”：礼物、公司报销、家长付款、机构采购。

- 是否存在多人共同决策；家庭/团队内部谁拥有否决权。

### 2.3 使用者节点与“平均用户”问题

平均值会掩盖混合分布。一个市场可以同时存在少量高痛点、高支付意愿用户与大量低痛点、低支付意愿用户；若只观察总体转化率，可能错误否定高价值细分，也可能把少数极端用户的行为外推到多数人。此节点因此要求保留分层样本，而不是只保存均值。

## 3. 场景：行为发生的时空、任务与注意结构

场景不是“地点标签”。它是由物理环境、社会环境、时间结构、任务定义与前置状态共同构成的行为条件集合。Belk（1975）在消费者研究中提出的五类情境变量——physical surroundings、social surroundings、temporal perspective、task definition、antecedent states——与本架构的场景节点高度兼容。

### 3.1 因果机制

场景至少通过四条路径改变行为：第一，改变选项是否可见与是否进入注意；第二，改变行动成本，如距离、等待、支付、离开当前任务的代价；第三，改变当前任务优先级与情绪状态；第四，改变社会规范与可接受行为。Tversky 与 Simonson（1993）进一步说明，选择偏好可以依赖局部选择集合；Bitner（1992）的 servicescape 框架则强调物理环境对顾客和员工行为的系统影响。

因此，“人流”必须分解。经过一个点位只表示物理接近；真正的商业链条至少还包括视觉接触、注意、需求激活、考虑、接近、支付和完成。Honka、Hortaçsu 与 Vitorino（2017）在银行市场中实证区分 awareness、consideration 与 choice，说明这些阶段不应合并为一个转化指标。

### 3.2 子样本空间：场景变量

- 物理位置：室内/室外、楼层、入口/出口、主通道/支路、可视距离、遮挡。

- 地理尺度：社区、校园、医院、园区、交通枢纽、景区、县域、城市核心区。

- 接近成本：步行距离、楼层变化、绕行距离、停车、安检、门禁。

- 可见性：视线高度、照明、标识、拥挤遮挡、屏幕亮度、陈列。

- 声学与气味环境：是否干扰注意、形成厌恶或促进停留。

- 温度、天气、海拔、季节、昼夜等自然条件。

- 人流量、停留量、回访量；分别记录，不合并。

- 人流目的：通勤、办事、看病、学习、娱乐、旅游、等待、陪同。

- 有效客流：与产品任务相关且具备行动条件的人群比例。

- 停留时长分布：中位数、长尾、极短停留比例。

- 等待性质：焦虑等待、确定性等待、无聊等待、可自由离开等待。

- 时间压力：是否有截止时间、叫号、登机、上课、考试、医生通知。

- 任务定义：当前主要任务是否与购买相容，是否会把购买视为干扰。

- 前置状态：饥饿、口渴、疲劳、疼痛、焦虑、现金不足、手机没电。

- 社会环境：独处、家人陪伴、同事在场、陌生人密集、权威人员在场。

- 消费规范：场景是否鼓励逛、看、试、停留；是否有“办完就走”的规范。

- 离开便利性：能否随时离开场景去外部商店；离开是否失去排队/座位/机会。

- 周边供给：便利店、食堂、自动售货、外卖、熟人、单位内部供给。

- 营业时间错位：需求高峰是否发生在人工供给关闭之后。

- 支付基础设施：现金、扫码、网络、信号、发票、报销。

- 制度条件：场地租赁、分成、准入、消防、卫生、数据、安全、采购。

- 供给维护：补货、维修、清洁、故障响应、库存监测的可达性。

- 事件冲击：考试周、节假日、展会、政策、施工、疫情、旅游旺季。

- 重复暴露：同一人是否每天经过；熟悉度如何改变注意和信任。

- 拥挤度：拥挤既可能增加流量，也可能抑制停留与支付。

- 私密性：购买行为是否会被他人观察；某些品类对隐私高度敏感。

- 空间所有权与控制权：好位置是否可租、可签独家、可被管理方撤回。

### 3.3 场景节点的识别原则

> **人流不是需求的代理变量**<br>高人流只有在“相关需求出现—注意进入—行动成本可接受—支付/使用可完成”这条链上同时成立时，才可能转化为有效客流。场景分析应优先记录转化链各段，而不是把总经过人数当作商业容量。

## 4. 替代方案：真实竞争集合与非市场外部选项

替代方案节点用于回答：当行动者不选择我们的方案时，他究竟做了什么。传统竞品表只能覆盖“市场内替代”，而大量现实行为发生在市场之外：自己解决、让熟人解决、延迟、降低要求、改变任务、忍耐或完全不行动。

### 4.1 理论解释

Coase（1937）指出使用市场价格机制本身存在搜索、谈判与缔约成本。这意味着“买一个解决方案”不是零成本基线；自助、组织内部处理或关系网络可能在特定交易上更便宜。Becker（1965）的时间配置/家庭生产视角进一步提示，家庭会组合时间与市场商品生产最终效用，因此时间、家务劳动和购买之间可以替代。

Granovetter（1985）的社会嵌入视角反对把经济行动理解为脱离社会关系的原子化选择。Townsend（1994）对村庄风险分担的研究则展示了正式市场之外的互助与保险机制。对县域、小组织、校园和熟人密集环境而言，社会网络可能成为供给的一部分，但其强度必须通过本地证据验证，不能由理论直接推断。

### 4.2 替代方案分类

| **替代类型** | **机制** | **示例** |
| --- | --- | --- |
| 直接市场替代 | 同品类、同功能、同价格带的竞争产品/服务。 | 另一款清理软件；另一台售货机。 |
| 跨品类替代 | 用不同产品满足同一底层任务。 | 便利店替代售货机；云盘替代本地清理。 |
| 内部生产 | 自己花时间、技能或组织资源完成。 | 手动删文件；单位 IT 处理。 |
| 关系型替代 | 家人、朋友、同学、同事、熟人网络提供资源。 | 让陪护家属带水；让同学修电脑。 |
| 延迟 | 把问题移到未来处理。 | 回家再喝；磁盘满了再清。 |
| 规避 | 改变行为以避开问题。 | 不装大型软件；少拍视频。 |
| 降级 | 接受更差结果以降低解决成本。 | 忍受慢；买更便宜但较差方案。 |
| 不行动 | 维持现状。 | 什么都不装、什么都不买。 |

### 4.3 子样本空间：外部选项

- 直接竞品的价格、功能、品牌、渠道、服务、默认安装、预装优势。

- 免费竞品、开源方案、系统自带功能、平台赠送服务。

- 人工服务、线下服务、远程服务、DIY 教程、论坛/搜索引擎。

- 自助所需时间、技能、犯错成本、学习成本。

- 熟人帮助的可得性、响应时间、互惠义务、关系成本。

- 家庭成员能否顺路采购、代办、垫付、陪同。

- 组织内部资源：IT、行政、采购、导师、同事、设备共享。

- 延迟的代价：问题是否恶化；是否存在硬截止时间。

- 忍耐阈值：不适、损失或麻烦达到什么程度才触发行动。

- 放弃任务的代价：用户是否可以直接不做这件事。

- 替代方案的可逆性与风险：用户为何宁愿用更差但更熟悉的方案。

- 替代方案的可见性：用户是否知道存在；是否进入考虑集合。

- 替代方案的社会认可度：朋友/单位是否推荐或禁止。

- 替代方案的锁定：历史数据、账号、习惯、设备、合同。

- 跨场景替代：当前不买，是否可以在回家、到公司、到市区后解决。

- 跨时间替代：即时需求是否可被未来更低成本供给替代。

- 自我约束：用户是否主动限制消费、流量、时间、娱乐等需求。

- 非货币交换：人情、互助、资源交换是否替代现金交易。

## 5. 从知道到行动：采用摩擦、信任与风险转移

该节点专门处理“价值已经存在，但用户仍然不采用”的中间过程。它把 awareness、consideration、evaluation、trial、adoption、confirmation 分开，并把信任、权限、风险、迁移、学习和可撤销性作为独立变量。

### 5.1 信息不对称与“陌生人测试”

Akerlof（1970）的“柠檬市场”说明，当卖方比买方更了解质量时，质量不确定性可以破坏交易；2001 年诺贝尔经济学奖对 Akerlof、Spence 与 Stiglitz 的总结进一步区分了 adverse selection、signaling 与 screening。对软件而言，开发者知道代码行为，用户只观察到界面、品牌、权限请求、第三方评价和历史记录。真实质量因此不会自动进入用户决策。

> **陌生人测试**<br>删除“这是我做的”这一信息。把产品改写为：一个完全陌生的人提供的工具，要求我付费、安装、授权、上传数据或承担不可逆风险。然后重新判断自己是否愿意采用。该测试的作用不是模拟所有用户，而是剥离开发者掌握的私有信息与自我信任，暴露信息不对称。

### 5.2 现状偏差、转换成本与采用

Samuelson 与 Zeckhauser（1988）发现决策者对现状选项存在系统性偏好；Klemperer（1987）则从产业组织角度把学习成本、交易成本和企业制造的转换成本纳入竞争。两者不能混为一谈：前者包含行为偏好，后者可以是完全真实的经济成本。实践中应分别测量“客观迁移成本”和“主观不愿改变”。

Rogers 的创新扩散传统把 relative advantage、compatibility、complexity、trialability 与 observability 作为影响采用速度的重要属性；Young（2009）则从社会学习、社会影响与 contagion 的不同机制解释扩散曲线。采用慢因此不能自动解释为无价值，也不能自动解释为“用户保守”，需要识别具体机制。

### 5.3 子样本空间：采用链

- 发现渠道：搜索、广告、朋友、应用商店、预装、组织推荐、线下陈列。

- 品牌/产品是否进入 awareness；知道名字是否知道用途。

- 用户是否理解核心价值；是否能在十秒内判断与自己相关。

- 产品是否进入 consideration set；为什么被排除。

- 信息成本：要读多少说明、比较多少参数、看多少评价。

- 质量可验证性：采用前可验证、采用后可验证、长期才可验证、几乎不可验证。

- 信号：开源、代码签名、第三方审计、品牌、用户规模、案例、保修、退款、认证。

- 信号成本是否足以区分高质量与低质量提供者；廉价口号不应与可信信号等价。

- 权限：管理员权限、文件删除、通讯录、相册、定位、支付、企业数据。

- 风险暴露：误删、停机、泄露、损坏、封号、合规、声誉、身体安全。

- 最坏结果的严重度与可恢复性。

- 可撤销性：撤销、回滚、备份、预览、沙箱、只读模式、分阶段授权。

- 首次使用成本：下载、安装、注册、验证、绑定、导入、配置。

- 学习成本：是否需要教程、专业术语、长期训练。

- 迁移成本：数据、习惯、插件、账号、工作流、组织流程。

- 兼容性：设备、操作系统、文件格式、组织制度、现有工具链。

- 试用性：是否可以小范围、低权限、低金额、短周期试验。

- 结果可观察性：用户能否快速看到收益；是否能归因于产品。

- 社会证明：同类用户、熟人、专业人士的采用是否可见。

- 支付摩擦：价格展示、支付方式、订阅规则、退款、发票。

- 中断：注册中断、支付中断、下载失败、权限拒绝后是否流失。

- 确认阶段：采用后是否持续寻找支持/反对信息；是否反悔。

- 售后与故障恢复：失败时谁承担成本，恢复时间多长。

- 默认选项：系统默认、组织默认、浏览器默认、应用商店排序。

- 退出成本：卸载、导出数据、取消订阅、恢复旧工作流。

### 5.4 清理软件实例：信息结构而非功能清单

对具有文件删除能力的清理软件，关键问题不应只写成“能否释放更多空间”。采用链同时包含：用户是否相信扫描结果、是否理解删除对象、是否担心误删、是否能预览差异、是否有回滚、开发者身份是否可信、程序是否签名、权限是否过高、失败后恢复成本多大。这里的主要矛盾可能不是功能不足，而是“收益可见、风险不可完全验证”的不对称结构。

因此，开源、只读扫描、删除前 diff、可恢复回收站、最小权限、明确数据边界、代码签名和第三方复核等措施应被视为降低信息与风险摩擦的机制候选，而不是单纯的“营销包装”。其真实效果仍需通过采用率、授权率、完成率、误删率和留存数据验证。

## 6. 市场与竞争：从“存在利润”到“利润归属与持续时间”

市场与竞争节点负责把需求存在与行动者收益分开。一个市场可以有真实需求和正毛利，同时对新进入者极差；也可以竞争者很多但仍有局部细分、空间差异或快速增长容纳新进入。市场空白因此只是一条观测，不是结论。

### 6.1 空白市场的解释问题

Bresnahan 与 Reiss（1991）的经验进入研究把企业进入决策视为关于市场规模、利润与竞争强度的信息；其结果同时说明新增企业会改变竞争本身。由此可得到一个稳健的实践含义：看到“没人做”时，既不能直接写成蓝海，也不能直接写成无需求。应调查潜在进入者过去是否尝试、进入成本、退出记录、市场规模、竞争反应和不可观测的本地条件。

OECD 对进入壁垒的综述指出，Bain 与 Stigler 对“进入壁垒”的定义并不相同，后续产业组织又强调 sunk costs、战略承诺和动态进入。因而“门槛高/低”也不能用一个标签概括：资本要求若对 incumbents 与 entrants 对称，其竞争含义与 incumbents 已经沉淀了品牌、渠道、数据、学习曲线完全不同。

### 6.2 固定竞争四问

| **问题** | **研究对象** | **主要变量** |
| --- | --- | --- |
| 我能来吗？ | 当前行动者是否具备进入资格与资源。 | 资本、许可、渠道、技术、供应、场地、最低规模、时间、合规。 |
| 我来了，别人能来吗？ | 成功是否会迅速吸引复制。 | 模仿成本、专利、数据、独家、学习曲线、品牌、渠道、网络效应。 |
| 别人来了，我还能活吗？ | 竞争后利润是否仍成立。 | 市场增长、容量、价格战、固定成本、差异化、细分、区域隔离。 |
| 别人提前来了，我凭什么还能来？ | 面对 incumbent 的非对称位置。 | 先发资产、转换成本、用户习惯、独家点位、规模、互补资产；我的反向优势。 |

### 6.3 价值捕获：创新者不一定拿到钱

Teece（1986）明确讨论了为什么创新企业可能无法获得创新产生的经济回报：当模仿容易、互补资产关键时，收益可能流向制造、分销、渠道、品牌或其他资产所有者。这个结论直接修正“技术领先 → 商业领先”的跳跃。对个人开发者而言，应用商店分发、企业采购渠道、可信品牌、售后能力、数据入口等都可能比核心代码更接近价值捕获瓶颈。

Lieberman 与 Montgomery（1988）对先发优势的综述强调，先发优势来自具体机制，而不是时间顺序本身。Dierickx 与 Cool（1989）进一步指出，一些战略资产只能通过时间积累，存在 time compression diseconomies、asset mass efficiencies、causal ambiguity 等特征。由此，“别人提前来了”应拆解为对方究竟积累了什么，而不是简单写成“先发优势”。

### 6.4 竞争优势与可模仿性

Barney（1991）和 Peteraf（1993）的资源基础视角把持续优势建立在资源异质性、模仿限制、资源流动限制以及竞争前后的租金保护条件上。对本框架而言，它们最有价值的不是 VRIN 等术语本身，而是迫使分析者区分：资源是否真的稀缺、别人能否买到、能否复制、复制需要多久、复制前利润窗口多长。

网络效应还会产生另一类动态。Katz 与 Shapiro（1986）表明，技术采用在网络外部性存在时具有路径依赖与战略优势；这意味着“产品本身更好”未必足以逆转既有网络。但同样不能看到平台就喊网络效应，必须验证用户价值是否真的随其他用户/互补者数量上升。

### 6.5 子样本空间：市场结构与进入

- 市场边界：地理、品类、用户、场景、价格带、渠道边界如何定义。

- 市场规模：用户数、交易频次、客单、可服务比例、可获得比例。

- 增长率：新增需求还是存量替代；增长是否足以抵消进入。

- 竞争者数量、规模分布、集中度、地域覆盖、产品差异。

- 历史进入者与退出者：进入时间、退出时间、退出原因。

- 潜在进入者：已有相邻能力、渠道或客户基础的企业。

- 固定成本、沉没成本、可回收成本；退出时能回收多少。

- 最低有效规模；未达到规模时单位成本如何变化。

- 供给弹性：需求增长后供给能多快跟上。

- 价格竞争强度；促销依赖；是否存在长期低价补贴。

- 差异化维度：功能、质量、位置、速度、服务、品牌、兼容、隐私。

- 用户转换成本与多归属：是否可以同时使用多个供应商。

- 渠道控制：应用商店、平台流量、线下点位、经销商、采购目录。

- 独家与排他：点位、渠道、供应、数据、协议、合作伙伴。

- 监管与许可：行业资质、数据、支付、消防、卫生、广告、劳动。

- 供应商议价力：关键输入是否集中；是否会吞噬利润。

- 买方议价力：大客户是否能压价、要求定制、延长账期。

- 互补资产：制造、分发、售后、品牌、认证、数据、服务网络。

- 模仿时间：功能复制、供应链复制、品牌复制、关系复制分别多久。

- 学习曲线：经验是否显著降低成本/故障/获客。

- 网络效应：用户数是否提高其他用户价值；直接/间接网络效应。

- 规模经济：平均成本是否随规模下降；规模是否也增加管理成本。

- 先发资产：标准、默认、心智、数据、独家、安装基数。

- 后发优势：更低技术成本、规避教育市场、学习前人错误、兼容新标准。

- 替代技术：是否可能绕过整个行业，而不是只出现新竞争者。

- 利润归属：价值最终被开发者、渠道、平台、场地方、供应商还是用户拿走。

- 利润持续期：几周窗口、几年稳定、还是需要持续创新维持。

- 竞争反应：降价、复制、封锁渠道、提高租金、签独家、捆绑。

- 局部市场：全国拥挤是否仍存在地域、行业、场景或用户细分。

### 6.6 “空白怀疑”与反命题

> **双向先验**<br>在低门槛、信息充分、存在时间较长的领域，明显空白应优先调查“为什么利润没有被吃掉”；但这只是先验。技术成本变化、政策变化、基础设施变化、新渠道、新消费习惯、局部信息摩擦、需求快速增长或行动者特殊资源，都可能使旧均衡失效。空白是待解释观测值，不是机会证明，也不是死亡判决。

## 7. 我为什么做它：行动者约束、选择权与失败残值

前六个节点回答“这个机会在外部世界是否成立”；第七节点回答“为什么由我、在现在、以这种承诺程度进入”。它防止把市场层面的正收益偷换成个人层面的最优选择。

### 7.1 机会成本与真实期权

机会成本要求比较现实替代方案，而不是比较“做项目”和“什么都不做”。Dixit（1992）关于不确定性投资的真实期权分析指出，在不可逆投入与不确定性并存时，等待具有正价值，因为时间带来信息。于是决策集合至少包括：立即重投入、延迟、低成本试验、购买信息、保持选择权、退出。

McGrath（1999）把真实期权推理引入创业失败：在不确定性高时，可以通过小规模承诺保留高方差上行，同时限制下行损失。这个视角比“失败也能学到东西”更严格，因为学习只有在成本受控、信息可用于后续决策、且试验确实改变后验判断时才有价值。

### 7.2 探索、利用与能力积累

March（1991）区分 exploration 与 exploitation，并指出两者收益的时间分布不同：利用更快反馈，探索更不确定但可能产生长期适应性。Cohen 与 Levinthal（1990）的 absorptive capacity 又说明，先前相关知识影响识别、吸收和利用外部知识的能力。因此，一个短期收益一般的项目仍可能通过积累相关能力提高未来机会集合；但只有当这种能力可迁移、可复用且与未来方向相关时，这一“残值”才成立。

Dierickx 与 Cool（1989）的资产积累逻辑也提醒：某些能力不能在需要时瞬间购买。长期信誉、客户关系、技术栈熟练度、数据、运维经验、渠道关系等可能具有路径依赖。因此，第七节点不仅比较现金回报，还要记录项目是否构成可积累资产。

### 7.3 子样本空间：行动者—项目匹配

- 现金投入：启动资金、保证金、设备、注册、租赁、库存、软件、订阅。

- 持续现金流：服务器、维护、税务、会计、场地、人工、交通。

- 最坏现金损失与流动性风险；失败是否需要借债。

- 时间投入：一次性开发、持续运营、客服、补货、维护、销售。

- 注意力成本：是否占用主业最稀缺的深度工作时间。

- 学习曲线：多久达到最低可用能力；是否与已有知识相邻。

- 验证周期：几小时、几周、几个月、几年才能知道关键假设是否错误。

- 验证成本：最便宜的证据是什么；是否必须先做完整产品。

- 不可逆投入：公司注册、长期合同、专用设备、声誉承诺、团队雇佣。

- 可逆投入：可退设备、按月订阅、短期试点、临时合作。

- 退出成本：注销、库存处理、合同违约、客户迁移、数据清理。

- 失败残值：代码、作品集、论文、客户、渠道、行业知识、证书、数据。

- 失败残值的可迁移性：只能用于本项目还是能迁移到下一项目/求职。

- 成功后的维护负担：是否形成长期值守、客服、合规和运维债务。

- 项目是否锁定地理位置、行业、技术栈、身份或时间安排。

- 与主业冲突：考试、课程、Lab、实习、求职、考研、健康与休息。

- 现实替代方案：同样的钱和时间还能获得什么。

- 收益分布：高概率小收益、低概率大收益、尾部损失。

- 收益到账时间：现金回收周期、账期、订阅回本周期。

- 信息价值：试验能否区分两个关键机制；还是只产生更多模糊数据。

- 停止规则：出现什么证据立即停止；什么证据才追加投入。

- 追加投资条件：里程碑、留存、付费、毛利、故障率、渠道验证。

- 资源非对称：我有什么别人没有/暂时难复制的资源。

- 资源缺口：即使市场好，我缺的关键资产能否买到或合作获得。

- 身份与合规约束：学生、个人、公司主体、就业/实习冲突。

- 声誉风险：失败是否影响后续合作、求职、客户信任。

- 学习价值是否被自我美化：若项目完全失败，具体可验证的能力资产是什么。

- 选择权：做了以后会打开哪些门、关闭哪些门；不做是否保留更大选择集合。

### 7.4 “可以做”与“应该做”的逻辑分离

> **决策边界**<br>前六节点全部通过，只能得到“外部机会可能成立”；第七节点通过，才可能得到“当前行动者值得以某种投入强度进入”。反之，第七节点否决并不说明市场不存在，只说明资源配置不适合当前行动者。

## 8. 跨节点因果连接：把七个抽屉连成图

七节点如果只作为检查清单，会再次退化为术语堆积。更稳健的用法是保存跨节点边。以下连接不是数学模型，而是描述性因果语法，用于提示需要共同观测的变量。

| **连接** | **因果含义** | **优先观测** |
| --- | --- | --- |
| 需求 × 使用者 | 同一客观问题在不同资源、风险偏好、任务状态下产生不同的行动压力。 | 分层转化率；不同人群的搜索/支付/忍耐。 |
| 使用者 × 场景 | 瞬时状态与场景共同决定注意和决策策略。 | 同一人在不同场景的行为；同一场景不同任务人群。 |
| 场景 × 替代方案 | 场景改变外部选项的可得性与成本。 | 外部商店距离、离开排队成本、熟人可达性。 |
| 需求 × 替代方案 | 问题强度只有相对于替代方案成本才产生购买。 | 忍耐阈值、DIY 时间、替代价格。 |
| 替代方案 × 采用 | 即使本产品更好，现状/旧方案的转换成本也可能阻断采用。 | 迁移时间、数据锁定、学习成本。 |
| 使用者 × 采用 | 风险承担者、付款者、使用者分离时，采用需要多方同时通过。 | 审批链各环节拒绝率。 |
| 采用 × 市场竞争 | 品牌、信号、默认、网络效应与转换成本既影响用户采用，也形成竞争结构。 | 获客成本、留存、转换率、渠道份额。 |
| 市场竞争 × 我为什么做它 | 市场利润结构必须投影到行动者的资源、时间和不可逆承诺。 | 最低资本、验证周期、退出成本。 |
| 我为什么做它 × 市场竞争 | 行动者已有资源也会改变其可进入的市场边界。 | 渠道、技能、关系、品牌、数据等非对称资产。 |

### 8.1 证据强度与更新

- 优先级高：真实交易、留存、价格实验、A/B、库存/流量日志、自然实验、明确的进入/退出记录。

- 中等：结构化访谈、现场观察、竞品历史、运营人员记录、公开财务/政策数据。

- 较弱：问卷意愿、社交媒体抱怨、单个用户故事、自己作为开发者/创业者的直觉。

- 理论证据不能直接替代本地参数。理论说明“机制可能存在”，项目数据说明“机制在这里有多强”。

- 每个重大结论应保留竞争解释。若两个机制产生同一观测，应设计能区分它们的数据，而不是继续争论。

## 9. 两个实践样本如何进入结构

### 9.1 县城医院自动售货机：作为反例样本而非行业结论

以下内容只整理既有讨论形成的待验证机制，不把它们外推为“县城医院普遍规律”。其价值在于展示如何把一个直觉点位拆成可检验变量。

| **节点** | **当前机制假说** | **需要的数据** |
| --- | --- | --- |
| 需求 | 口渴/饥饿是客观状态，但购买行为取决于是否愿意立即解决；“能忍”是外部选项而不是需求消失。 | 购买率、忍耐时长、夜间需求、价格弹性。 |
| 使用者 | 看病者/陪护者可能处于焦虑、疲劳、注意集中于医疗任务的状态；不同角色需分开。 | 患者/陪护/医护分层；停留时长；支付者。 |
| 场景 | 医院可能具有高人流但低非任务消费倾向；轻症短停留、重症转诊等判断需要当地数据验证。 | 分时段停留、科室流量、夜间供给、外出成本。 |
| 替代 | 忍耐、回家、外出购买、家属带来、熟人帮助均可能替代机器。 | 替代使用比例、外部商店距离、家属陪同率。 |
| 采用 | 售货机采用摩擦较低，但可见性、价格显著性、支付与商品匹配仍重要。 | 看见→接近→支付漏斗。 |
| 竞争 | 好点位可能已被占用；空白点位可能反映差经济性，也可能反映管理/准入问题。 | 历史运营商、点位合同、租金/分成、退出记录。 |
| 我为什么做 | 设备、补货、维护与点位合同形成持续运营负担；需要与其他机会比较。 | 回本周期、维护半径、最坏损失、退出回收。 |

### 9.2 陌生人清理软件：高权限工具的采用问题

| **节点** | **结构化描述** | **需要的数据** |
| --- | --- | --- |
| 需求 | 磁盘空间不足/系统臃肿不等于付费清理需求；用户可能手动清理、扩容或忍耐。 | 搜索、手动清理、付费、卸载、复购。 |
| 使用者 | 普通用户与技术用户对权限、可解释性、自动化的偏好可能相反。 | 按技术熟练度分层。 |
| 场景 | 紧急磁盘爆满与日常维护是不同任务；前者时间压力高，后者行动动机低。 | 触发场景、问题严重度。 |
| 替代 | 系统自带、手动删除、第三方工具、云盘、换盘、重装。 | 真实替代路径及成本。 |
| 采用 | 陌生开发者要求删除权限形成强信息不对称与风险暴露。 | 权限授权率、只读扫描完成率、回滚需求、信任信号。 |
| 竞争 | 成熟工具拥有品牌、签名、用户规模、渠道；新工具需解释为何仍能进入。 | 差异化、分发、信誉、复制成本。 |
| 我为什么做 | 若商业回报弱，项目是否仍形成可迁移代码/安全/运维/产品能力，需要单独核算。 | 时间投入、作品残值、替代学习项目。 |

## 10. 理论节点注册表：以后如何继续“读书而不是只思考”

后续新增理论时，不增加一级节点，而新增“理论节点记录”。每个理论节点至少保存以下字段，以防止理论退化为术语装饰。

| **字段** | **记录要求** |
| --- | --- |
| 理论名称/文献链 | 原始文献、关键后续修正、主要综述。 |
| 核心机制 | 理论主张的因果过程，而非一句定义。 |
| 分析单位 | 个人、家庭、组织、企业、市场、网络、制度。 |
| 适用条件 | 机制成立需要哪些前提。 |
| 主要可观测量 | 哪些数据能支持或削弱该机制。 |
| 可混淆机制 | 哪些理论会产生相似观测结果。 |
| 反证/边界 | 什么证据出现时不能继续套用。 |
| 连接节点 | 连接七节点中的哪些位置以及连接方向。 |
| 实践翻译 | 能产生什么新的调查问题、实验或停止规则。 |
| 状态 | 候选/已阅读/已验证/被削弱/被替代。 |

### 10.1 建议的纵向阅读链

| **阅读链** | **建议顺序** |
| --- | --- |
| 选择与需求 | Samuelson → revealed preference → limited attention / consideration sets → rational inattention → intention–behavior gap。 |
| 场景与行为 | Belk → context-dependent preference → salience → servicescape → task/time pressure 与情绪决策。 |
| 信任与采用 | Akerlof → Spence/Stiglitz → signaling/screening → switching costs/status quo → diffusion/adoption。 |
| 市场进入 | Bain/Stigler 争论 → empirical entry models → first-mover mechanisms → complementary assets → resource-based persistence。 |
| 不确定性行动 | Knight uncertainty → real options → entrepreneurial experimentation → exploration/exploitation → capability accumulation。 |
| 社会替代 | Coase transaction costs → household production/time allocation → embeddedness/social networks → informal insurance/互助。 |

### 10.2 原创概念的保留标准

可以继续保留“陌生人测试”“空白怀疑”“竞争四问”等实践语言，但它们应被视为压缩接口，而不是新理论。一个原创概念只有同时满足三项条件才值得长期保存：第一，能压缩多个成熟机制而不扭曲它们；第二，能生成新的可观测问题或实验；第三，能明确指出自己的失败条件。否则宁可保留原理论节点。

## 11. 当前版本的稳定结论与开放问题

本轮深度研究没有发现必须推翻七节点骨架的证据。相反，七节点分别对应多个成熟研究传统，但这些传统的边界与交叉关系要求我们把框架从“七个问题”升级为“七个经验索引 + 多对多理论图 + 证据元数据”。这比继续发明新的一级概念更稳定。

当前最需要防止的三类退化是：第一，把理论名词当作结论；第二，把单次项目经验外推为一般规律；第三，把七节点重新使用成机械清单。后续最有价值的工作不是继续扩展一级节点，而是选择一个具体项目，把真实数据写入节点，再沿一个理论链纵向阅读并修正因果解释。

> **版本原则**<br>骨架稳定，节点可增密；理论可替换，证据可更新；经验允许被反证；任何结论保留竞争解释。目标不是让框架越来越复杂，而是让同样一次思考携带更多可验证信息。
